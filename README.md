## "三网直连"到底指什么，怎么自己验证

判断一台香港 VPS 是不是真三网直连，只看商家有没有把去程和回程写清楚，写了哪几条你就对照哪几条。

电信方向看 CN2。CN2 是中国电信的下一代承载网，里面还分两档：GT 是普通优先，晚高峰照样有波动；GIA 全程有 QoS 保障，才是大家说的"精品中的精品"。商家只写"CN2"不写 GT 还是 GIA，基本可以按 GT 理解。

联通方向看 9929（AS9929）或 4837。移动方向看 CMIN2 或 CMI。回程同样重要，去程优化、回程绕美国的方案，白天测速好看，晚上照样卡。

按这个标准去看 Akile 香港，会发现它没有对 HKS 系列做"三网各走精品线"的承诺。2024 年公开的一次路由测试记录显示，当时香港 BGP 系列的去程是电信和联通都走 AS10099、移动双向走 CMI，电信回程走 163。这套组合的定位是国际 BGP 优化，不是 CN2 GIA 那种回国精品线。产品参数结构也印证了这一点：500Mbps 起步的带宽配上 200G 起步的流量，是典型的"大管子、小水表"设计。

所以先回答自己一个问题。你要的是晚高峰稳定、三网各走精品的回国线路，还是香港物理位置带来的低延迟加一个大带宽数字？答案不同，选的产品完全不同。
